# 20%–25%年化目标候选：趋势动量轮动

这是一套独立的研究候选，不是当前服务器上运行的模拟策略。

## 核心逻辑

- 只使用BTCUSDT、ETHUSDT现货和现金，不做空、不加杠杆。
- 价格同时站上快慢EMA，并且慢EMA向上时，才允许持有该币。
- 每2天比较一次BTC和ETH过去20天的动量，选择更强的一只。
- 两只币都不符合上涨趋势时持有现金。
- 最多使用33%的总资金，剩余67%保留为现金，用于限制回撤。
- 信号产生后在下一根4小时K线开盘成交。
- 回测包含单边0.10%手续费和单边0.05%滑点。

## 运行方法

```bash
python3 rotation_research.py \
  --symbols BTCUSDT ETHUSDT \
  --interval 4h \
  --start 2020-01-01 \
  --end 2026-08-01 \
  --strategy-config configs/rotation_growth_20_25.json
```

结果保存在 `rotation_reports/`，不会修改 `paper_state/`。程序还会检查中心参数附近的27组组合，防止只挑中一个孤立的幸运参数点。

## 如何理解20%–25%目标

20%–25%是完整牛熊周期的历史研究目标，不是每年承诺，也不是月收入目标。完整历史中达到目标，不代表2022年以来或未来每年都能达到。

这段历史和参数已经被查看，因此不能再称为隐藏测试。候选策略即使通过双倍成本和延迟成交压力测试，也只能进入一套全新的未来模拟盘；至少连续运行90天并达到交易数量、盈利、回撤和数据连续性门槛后，才能讨论极小资金实盘验收。

当前模块不读取API密钥，也没有交易所下单代码。
