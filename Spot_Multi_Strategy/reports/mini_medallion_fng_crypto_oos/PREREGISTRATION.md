## 来源、机制和证据等级

[Alternative.me 官方说明](https://alternative.me/crypto/fear-and-greed-index/)称指数每日发布、目前针对 BTC，数值 0–100；其经济解释是极端恐惧可能伴随过度抛售、极端贪婪可能伴随过度追涨。页面公开 `GET https://api.alternative.me/fng/?limit=0` 的完整历史接口，以及按日期固定的图片。2020-12 五个周三和 2021–2025 年间抽样图片的 HTTP 元数据目前可见当天更新时间，但这不是不可篡改的逐点版本证明。指数含 25% BTC 波动率和 25% 价格动量/成交量，另含社交、优势率、搜索等；与纯价格信号部分重叠，且提供者未公开完整历史计算版本。恐惧可能延续、贪婪可能持续，因此机制**不证明**未来收益。

固定证据等级 `retrospective_current_vintage_sentiment_snapshot_supported`。2021–2023 为回顾性开发段，2024–2025 是时间留出，**不是**独立前瞻 OOS；`independent_oos=false`，无论数值结果多好都不能宣称完整 Gate 通过。对历史 API 今天返回的数值，用历史静态图片的发布时间作有限旁证，但不假定二者逐日完全一致。若要进入实盘，须另建真实前瞻记录并核交易数据许可。[Alternative.me 许可](https://alternative.me/crypto/fear-and-greed-index/)要求展示数据时紧邻注明来源；[Binance Vision 条款](https://github.com/binance/binance-public-data/blob/master/TERMS_AND_CONDITIONS.md)另有限制。正式报告须明确注明上述两家来源，研究数据不直接用于自动实盘。

## 固定数据、信号与执行

信号仅从 Alternative.me 官方 API 的一次 `limit=0` JSON 响应读取，禁止换网站、补点或使用第三方回填。只要求 2020-12-30 至 2025-12-24 共 **1,821** 个连续 UTC 日记录，每天唯一；`timestamp` 须为该 UTC 日期内的 Unix 秒，`value` 为 0–100 的十进制整数字符串，`metadata.error=null`。响应的 URL、HTTP 状态、取回 UTC 时刻、字节数与 SHA-256 记入报告；原始完整响应不落盘。若任一指定日缺失、重复、超范围、字段异常或 HTTP/JSON 不合，立即封存 `DATA_FAILURE.json`，不计算策略结果。固定图片只用于有限的公开时点佐证，不批量抓取或从图片择优换值。报告保存 261 个周三原始整数值和对应规则方向，便于核算；这并不能恢复历史 API 未留存的过去版本。

从 2020-12-30 至 2025-12-24 每周三 UTC 的指数值，共 **261** 个。每个周一 00:00 UTC 只读取至少四天前那个周三的值，2021-01-04 首次决策，2025-12-29 最后一次；周三值 **≤25** 则下一周五币等名义权重做多，**≥75** 则做空，其余平仓持现金，恰为 25/75 时分别入场。相同方向连续周不额外换边；每周一按既定风险规模再平衡。无日内调整、训练或可选阈值。四个更早的周三 2020-12-02/09/16/23 只作为冻结账本接口的预热锚，不参与信号选择。

为复用已经测试的 4h 执行账本而不触碰旧代码，新增一个确定性、仅内存的信号适配器：四个预热周三的编码值固定 1000；之后第 `i` 个周三的编码值 `V_i=V_(i-4)+d_i`，其中 `d_i` 是上述 `+1/0/-1` 方向。执行账本仅对最新 `V_i` 和四周前 `V_(i-4)` 作符号比较，因而**严格等于**本假说方向；编码值不是市场数据，也不用于调参。合成测试须证明三个方向、边界 25/75、首尾周一、四天滞后和所有 261 次映射一致。

**交易仅限加密货币**：固定 Binance USD-M USDT 永续 `BTCUSDT, ETHUSDT, DOGEUSDT, LTCUSDT, BCHUSDT`。沿用已测试的官方月度 4h trade/mark/funding 档案加载与严格校验：2020-12-01 起预热，2021-01-01 至 2026-01-01 UTC 为完整 1,826 日五年样本；逐包核官方 `.CHECKSUM`，仅完整 UTC 日六根 bar 同时缺失时允许官方日档补齐，部分缺口、异常资金费或终点数据异常即封 `DATA_FAILURE`。原始 ZIP/CSV 不落盘，来源哈希、补档日记入报告。

初始权益 10,000 USDT，现金零息。每周一使用此前 30 个完整 UTC 日五币等权篮子日收益样本标准差估年化波动：`vol=std(ddof=1)*sqrt(365.25)`，`gross=min(3.0,0.30/vol)`，每币目标名义绝对权重 `gross/5`，仅信号决定共同正负或全现金；最大总名义杠杆 3×，不以杠杆掩盖低 Sharpe。同币、同波动目标和成本的始终做多作为固定对照。每侧手续费 10bp、基础滑点 10bp，另做 25bp 滑点压力；按实际资金费和旧仓方向入账，旧仓资金费先于周一调仓。以 trade 4h 开盘成交、mark 4h 开高低估值及不利路径计回撤。BTC/ETH 向零取整至 0.001，DOGE 至 1，LTC/BCH 至 0.01；不足 5 USDT 不成交并记执行 Gate 失败。每单不超过此前 30 完整日成交额中位数 1%；权益≤0 或 4h 不利权益低于总名义 5% 计风险失败。历史保证金阶梯与真实盘口冲击仍不能完整复刻。

## 一次性 Gate 与停止规则

主场景五年 CAGR≥40%（目标 40–60%，若高于 60% 照实报告）、日净收益 Sharpe>1.5、保守 4h 最大回撤≥−20%、日 Profit Factor>1.3；五个年度 walk-forward 折中至少四年同时净收益>0、日 PF>1、年内保守回撤≥−20%；60 个月正收益≥70% 且单月不低于−10%；按此前 30 完整日 BTC 涨跌 >+10% / <−10% / 其余列报三种状态；种子 `20261103`、10,000 条 21 日循环区块 Monte Carlo，至少 5% 路径同时通过四个主数值门槛且 CAGR 第 5 百分位>0。还须费用/资金费、容量、最小订单、维持保证金、终点空仓、三态齐全、独立 OOS 都通过；当前 `independent_oos=false`，完整 Gate 必然不通过。日 PF 定义为正日净收益绝对和/负日净收益绝对和。

只新增隔离信号读取器、适配器、runner、测试和本报告目录；不修改成熟策略基线、用户 futures/hybrid/rotation/paper_state、旧报告或旧研究代码。预注册与代码必须分开提交推送。正式仅运行一次：数据问题封 `DATA_FAILURE.json`，非预期代码错误封 `CODE_FAILURE.json`，有效结果不论盈亏封 `RESULT.json`，然后只读核对并推送。禁止重跑同一正式历史。即使数值通过，也只能讨论未来新鲜数据上的小仓位模拟，未经另行授权不实盘。
