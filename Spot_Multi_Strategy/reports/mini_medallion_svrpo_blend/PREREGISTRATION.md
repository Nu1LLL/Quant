# Cboe SVRPO 市场中性波动率溢价组合：预注册

本轮检验 Cboe S&P 500 Market-Neutral Volatility Risk Premia Optimized Index
（SVRPO）。其经济假说是同时卖出一月期约90%虚值 put 与110%虚值 call，
并买入更远虚值 put/call 构成定义风险价差，获取隐含波动高于实现波动的风险
溢价，同时降低股票方向暴露。Cboe 的公开设计目标是与美国大盘股票和固定收益
月度回报低相关。

提交本预注册前只读取官方方法文件和端点名称，未读取 SVRPO 历史指数值、
收益统计或相关性。

## 数据与固定窗口

- SVRPO 只使用 Cboe 官方 `daily_prices/SVRPO_History.csv`。
- 固定评价期 2016-09-12 至 2026-09-10；若不能完整覆盖则直接判定十年
  证据不足，不缩短窗口。
- 现有增长袖套为已经封存并计入成本的 `TQQQ_WTMF_SWITCH +
  BTC_TSMOM30_DD` 1x 组合日收益，不重算资产或参数。

## 固定场景

- SVRPO 单独测试 1x、2x、3x，超过1x的增量按年化4%融资。
- 两袖套组合固定为增长袖套与 SVRPO 各50%资本，每21个共同交易日恢复
  50/50，中间允许权重漂移；每单位换手单边5bp。选择等资本是为了避免已在
  VPN 实验暴露的“低波动低收益指数被逆波动权重过度配置”，不比较其他权重。
- 两袖套组合固定测试1x、2x、3x，增量敞口融资4%；另对组合1x应用一次
  冻结风险覆盖（63日波动、25%目标、3倍上限、8%/20%回撤阈值、0.3
  最低标量、0.05不交易带）。共七个场景。
- SVRPO 官方指数作为未另扣内部复制滑点的乐观上限；初始资本10,000美元。

## Gate 与统计检验

七个场景统一要求 Sharpe >= 1.5、CAGR >= 40%、最大回撤 >= -20%、
完整盈利年比例 >= 80%、最差滚动三年 Sharpe >= 1.0。使用21日循环区块
bootstrap 4,999次、固定种子2178309，统一BH校正，FDR <= 5%。

## 停止与实施边界

不根据结果修改期权执行价、权重、再平衡、成本、杠杆或风险覆盖，不追加其他
iron condor/butterfly指数比较。失败即封存；通过也必须核实指数历史中是否有
发布前回填、SPX期权整数合约与保证金是否允许10,000美元复制，并进行冻结
前瞻验证，不能直接授权实盘。
