# AlphaCentric Income Opportunities Class A（IOFAX）按揭信用路径预注册

## 固定假说与证据等级

固定产品为`IOFAX`。经济假说是非机构住宅按揭证券、结构化信用相对价值与利率对冲能够
赚取区别于股票beta、外汇carry、商品趋势和可转债套利的复杂性/流动性溢价；若真实NAV
在完整危机中仍有较高Sharpe，有限外部杠杆可能提高`$10,000`账户复利。不得在揭晓后
换成IOFIX、其他份额、按揭指数、私募基金或删掉2020年。

仓库在本预注册前从未下载、回测或记录`IOFAX`，本轮未查询其收益表、价格图、评级或
历史指标。因此固定`independent_oos=True`，表示本项目对完整调整NAV路径的首次读取。
产品若在样本中实质改变策略或管理人，连续性为硬Gate。

## 固定数据与覆盖 Gate

- Yahoo chart接口固定请求`IOFAX`从2014-01-01至2026-09-15的日调整净值。
- 首日不晚于2016-06-30，末日不早于2026-08-31，跨度至少10年，工作日覆盖率至少
  94%，最大相邻缺口不超过10个日历日；无重复、缺失、非有限或非正价格。
- 任一覆盖条件失败就在绩效前封存，不移动起点、不换份额、不拼接其他份额或指数。
- 调整NAV已反映基金内部管理、证券选择、对冲、融资、费用和分配，不重复扣内部成本。
- 绩效揭晓后才查SEC或发行人当前文件，核对准确份额、最低投资额、申赎、销售负担、
  存续及策略连续性。对普通新`$10,000`账户固定采用官方最高适用前端/递延销售费；
  官方不能证明可申购则执行Gate失败。另扣首尾各10bp平台摩擦。

## 固定账户与杠杆

- 初始资本`$10,000`；固定报告1x、1.5x、2x、3x、5x；高倍数只作压力测试。
- 首个收益日按总名义本金扣官方销售负担和10bp建立摩擦；末日按总名义本金扣适用递延
  销售负担和10bp退出摩擦。超过1x部分固定按年化4%/252融资。
- 日收益=`leverage * adjusted_NAV_return - external_cost - financing`；任何一日净收益
  <=-100%即归零且不得复活。

## 固定验证与停止规则

- Gate：CAGR>=40%、Sharpe>1.5、最大回撤>=-20%、PF>1.3、同一策略至少10年、
  独立首次读取、完整成本、`$10,000`当前可执行、账户未归零。
- 年度walk-forward至少8个完整年度折，至少80%的折同时收益为正、PF>1、回撤>=-20%；
  最差滚动三年Sharpe>=1.0。
- 1x固定5,000条63日循环区块Monte Carlo，seed`20150528`，报告四目标联合概率与分位。
- 固定状态段：成立至2019、2020–2022、2023以后；固定压力年：2020、2022、2025。
- NAV质量先于绩效解释：报告底层日收益零值比例和一阶自相关；零值比例>10%或一阶自相关
  绝对值>0.30时，`unsmoothed_daily_nav` Gate失败，防止非流动资产估值滞后虚增Sharpe。
- 揭晓后不得改变产品、份额、日期、费用、融资、杠杆档、Gate、状态段或Monte Carlo；
  失败即封存，不加入择时、不改信用敞口、不删除危机日。
