# 多市场成本门槛：实现结果

结论：股票/ETF、期权、期货、外汇、加密现货/永续的成本已可按时点统一换算为开平 bps 门槛。本实现没有硬编码某家券商的当前费率，因为费率会随账户、档位、市场和时间变化；数据必须逐行携带当时成本。

## 已完成

- 股票/ETF：quoted spread + 双边每股佣金 + 双边冲击 + 持有期融资/借券。
- 期权：quoted spread + 双边每张佣金/`premium*multiplier` + 双边跳点滑价 + 持有期储备。
- 期货：quoted spread + 双边每张佣金/`price*multiplier` + 双边跳点滑价 + 持有期储备。
- 外汇：quoted spread + 双边每百万佣金 + 双边冲击 + swap/rollover。
- 加密：quoted spread + 双边 maker/taker 费 + 双边冲击 + funding/借币。
- 成本引擎已接入分钟买卖执行器；缺少市场必需字段时直接拒绝，不用零成本继续。

## 验收结果

五类市场的手算样例通过；缺失和负佣金被拒绝；资金费收入不能把成本降到 spread+佣金+冲击以下；在相同预测上提高成本只会减少交易，不会增加交易。

这仍只是成本逻辑验收，不是真实 Alpha 收益结果。
