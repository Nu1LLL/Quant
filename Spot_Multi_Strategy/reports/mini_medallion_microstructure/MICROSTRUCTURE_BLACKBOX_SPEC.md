# 全市场分钟盘口黑盒：冻结架构与数据规范

状态：核心模型实现前冻结。没有真实盘口数据前只做合成测试，不发布收益结果。

## 市场与数据源

系统按统一接口覆盖：

- 加密现货/永续：Tardis `incremental_book_L2` + trades，或 CoinAPI/Kaiko L2；Binance 官方公共归档仅作为逐笔成交、aggTrades、1s/1m K线辅助，不能替代多年完整 L2。
- 美股/ETF：Databento MBO/MBP 或 Nasdaq TotalView；必须保留点时上市、停牌、退市和交易时段信息。
- 期货：Databento/CME 等 MBO/MBP；必须处理合约乘数、到期、换月、涨跌停和隔夜保证金。
- 期权：OPRA/Cboe 报价与成交；按标的、到期、执行价和看涨/看跌分层，必须建模宽点差、希腊值、提前行权与组合保证金。
- 外汇：Dukascopy tick 可作第一阶段报价数据；机构级研究升级到 Cboe FX/多场所深度，并明确单一经纪商报价不等于全市场订单簿。

当前环境未发现 Tardis、CoinAPI、Kaiko、Databento 或 Cboe 数据密钥。任何付费下载须在用户提供合法访问后进行，不绕过授权。

## 统一分钟盘口表

每个 `venue + symbol + minute` 至少包含：

- best bid/ask、L1/L5/L20 双边深度；
- 主动买/卖成交额与笔数；
- bid/ask 新增、撤单额；
- mid、microprice、spread、实际下一分钟可成交价；
- 合约乘数、最小价格跳动、费率、maker/taker 标志、资金费率或借券成本；
- 数据完整性、序列缺口、停牌/合成记录标记。

订单簿更新必须先按交易所序列号重建，再聚合到分钟；不能从分钟收盘价反推出历史盘口。

## 黑盒模型

1. **前向 HMM**：用收益波动、点差、深度、成交强度识别流动性/压力状态；只允许 filtering probability，禁止全样本平滑状态。
2. **RBF 核模型**：用固定随机傅里叶特征近似核，预测下一分钟方向概率和可成交中间价收益；所有标准化、核映射与回归只在训练窗拟合。
3. **交易 Gate**：只有当方向概率超过 0.58/低于 0.42，且预测收益覆盖点差、手续费、冲击和安全边际时，才输出买入/卖出，否则空仓。
4. **分数 Kelly**：默认四分之一 Kelly，单品种上限 25%，组合风险按相关性和市场类别再限额；估计不确定性越大，仓位越小。

输出不是模糊评分，而是可审计记录：时间、市场、品种、买/卖/空仓、概率、预测边际、成本门槛、HMM 状态概率、Kelly 仓位、有效期、模型版本。

## 全品种点时扫描

- 每个决策时点只扫描当时已上市且可交易的品种。
- 用过去 30 日成交额、点差、盘口深度、数据完整率、上市天数、做空/借券可得性筛选；阈值按股票、期货、期权、外汇、加密分别配置。
- 不允许用今天的幸存品种列表回填历史；期权和期货必须按当时可交易合约链生成候选。
- 一个 Alpha 可跨多个品种重复执行，但相关性高的信号合并风险，不能把同一因子伪装成大量独立 Alpha。

## “重复直到 Alpha 消失”规则

- 每个 Alpha 独立记录预测、订单、成交、滑点和净收益。
- 实盘监控滚动净边际、AUC/校准、实际与模拟滑点、成交率、容量和相关性。
- 当滚动净收益均值的保守下界不再大于 0、概率校准显著恶化、实际成本超过预算或市场结构改变时，自动降仓至 0。
- 停用后只能通过新的前向隔离验证重新启用；禁止为了恢复交易在线搜索阈值。

## 验证顺序

数据完整性 → 无泄漏单元测试 → purged walk-forward → 独立日期 OOS → 真实 spread/fee/impact → 不同状态 → block bootstrap/Monte Carlo → 影子盘 → $10,000 小仓位实盘。任何前置阶段失败，不进入下一阶段。
