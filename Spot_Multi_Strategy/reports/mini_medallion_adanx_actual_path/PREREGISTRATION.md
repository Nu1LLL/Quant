# AQR Diversified Arbitrage Class N 独立实盘路径预注册

## 固定假说与证据等级

本轮检验真实多套利风险溢价能否在完整周期内提供高于单一并购套利的收益质量。固定产品
为 AQR Diversified Arbitrage Fund Class N（`ADANX`），不在揭晓后替换为其他份额、
ETF、指数或同类基金。经济假说是把并购/事件、可转债、相对价值及其他套利来源放在同一
真实账户净值中，可能降低单一风险溢价的尾部集中度；这不是对上一轮 `QSPNX` 的参数修改。

仓库检索确认预注册前从未下载、回测或记录 `ADANX`，本轮也未查询网页、发行人收益表
或价格图。故固定 `independent_oos=True`，含义仅为本项目对该完整净值路径的首次读取，
不宣称纯前瞻时间 OOS。预注册提交后才允许首次下载逐日调整净值。

## 固定数据与覆盖 Gate

- Yahoo 公开 chart 接口，固定请求 `ADANX` 从 2009-01-01 至 2026-09-15 的日调整
  收盘价；调整价用于纳入基金分配。
- 首日必须不晚于 2009-02-28，末日不早于 2026-08-31，跨度至少 17.5 年，工作日
  覆盖率至少 94%，最大相邻净值缺口不超过 10 个日历日；无重复、缺失、非有限或
  非正价格。任何一项失败，就在绩效前封存，不改起点、不拼接、不换份额。
- 调整 NAV 已反映基金内部管理费、交易、融资、卖空和衍生品结果，不重复估算内部成本。
- 绩效揭晓后再查官方文件核对当前存续、Class N 最低投资额、申赎限制和策略范围；
  若 `$10,000` 不能正常持有，统计结果只能作为机制审计，执行 Gate 失败。

## 固定账户与杠杆情景

- 初始资本固定 `$10,000`；固定报告 1x、2x、3x、4x、5x。
- 每个情景仅在第一日建立、末日清仓，按总名义本金各扣 10bp；期间不把每日净值波动
  错算成换手。
- 超过 1x 的外部资金固定按年化 4%/252 扣融资成本。共同基金份额未必允许外部杠杆，
  因此 2x–5x 是数学压力测试，只有官方与券商约束另行通过后才可讨论执行。
- 日收益固定为 `leverage * adjusted_NAV_return - external_cost - financing`；任一日
  净收益 <= -100% 即账户归零，之后收益为零且不得复活。

## 固定验证与停止规则

- Gate：CAGR >= 40%、Sharpe > 1.5、最大回撤 >= -20%、PF > 1.3、样本至少
  17.5 年、首次读取独立路径、成本纳入、当前 `$10,000` 可执行、账户未归零。
- 年度 walk-forward 至少 15 个完整年度折，至少 80% 的折同时满足收益为正、PF > 1、
  折内回撤 >= -20%；最差滚动三年 Sharpe >= 1.0。
- 1x 固定运行 5,000 条、63 日循环区块 Monte Carlo，seed `20090115`；报告达到
  CAGR/Sharpe/回撤/PF 四项目标的联合概率和各指标分位数。
- 固定状态段：成立至2013、2014–2019、2020以后；固定压力年：2009、2020、2022。
  同时报告年度结果、最差滚动三年、最长回撤、全部外部交易及融资成本。
- 揭晓后不得改变产品、份额、日期、成本、融资、杠杆、Gate、Monte Carlo 或状态分段；
  失败即封存，不在同一历史上增加择时、删除危机年或试验“差一点”的版本。
- 只新增本轮包装、测试和报告；不修改提交 `d9861c9` 的成熟约20%策略、既有报告，
