# AQR Diversified Arbitrage Class N 独立实盘路径结果

## 结论

**完整 Gate 失败，不进入模拟或实盘。** `ADANX` 从 2009-01-15 至
2026-09-14 共 4,442 个净值日，工作日覆盖率 96.42%。独立首次读取的 1x 路径取得
4.14% CAGR、1.385 Sharpe、-14.73% 最大回撤和 1.302 Profit Factor。它通过样本、
独立性、成本、回撤、PF、年度 walk-forward 和 `$10,000` 产品可执行性 Gate，但
CAGR、Sharpe 严格大于1.5及最差滚动三年Sharpe三项失败。

初始 `$10,000` 的 1x 期末权益为 `$20,463.28`。该路径证明多套利机制确有稳定性，
但收益强度不足；4%外部融资不能把约4%的底层CAGR变成40%。

## 决策

封存`ADANX`买入持有和固定外部杠杆假说。不以2020后的较好状态缩短样本，不把
Sharpe 1.385四舍五入成1.5，也不降低4%融资成本。这个候选适合作为低回撤分散袖套，
但不能单独满足40% CAGR；若未来进入组合，只能在组合资产与权重揭晓前固定，并使用
新的前瞻期验证，不能与本仓库已知赢家事后拼接后宣称独立OOS。
