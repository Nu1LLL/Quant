# DAA-G12 多机制跨资产配置：覆盖Gate结果

## 裁决

**覆盖失败，绩效未揭晓，不进入实盘。** 固定15只ETF的共同历史始于
2007-04-11，晚于预注册的2006-08-31；跨度19.43年，也短于预注册的20年。
因此程序在任何收益、Sharpe、回撤、权重或Monte Carlo输出前主动终止。

不能在已经看见覆盖结果后删除HYG、缩短预热、移动起点或换成另一个信用债代理。
这次失败只说明固定ETF实现无法按承诺获得金融危机前的完整十二个月预热，不构成
对DAA经济假说的正面或负面绩效证据。

## 覆盖证据

| 项目 | 预注册要求 | 实际 | 通过 |
|---|---:|---:|:---:|
| 共同首日 | 不晚于2006-08-31 | 2007-04-11 | 否 |
| 共同末日 | 不早于2026-08-31 | 2026-09-14 | 是 |
| 共同跨度 | 至少20年 | 19.43年 | 否 |
| 工作日覆盖率 | 至少94% | 96.43% | 是 |
| 最大共同缺口 | 不超过10个工作日 | 2个工作日 | 是 |
| 重复/缺失/非正价 | 0 | 0 | 是 |

共同面板有4,888个交易日。瓶颈为HYG，其首条可用调整收盘价是2007-04-11；
其次GSG始于2006-07-21。其余标的均不改变上述共同起点裁决。

## 未产生的指标

CAGR、Sharpe、最大回撤、PF、年度walk-forward、压力期、持仓频率及Monte Carlo
均标记为**未计算**，而不是0或失败数值。这样避免在违反覆盖预注册后偷看绩效，
也避免把“没有结果”误报成“策略无alpha”。

## 数据与复现

数据来自Yahoo公开chart接口的调整收盘价，请求区间固定为2005-01-01至
2026-09-15。`coverage_audit.csv`保存机器可读裁决，`data_hashes.csv`保存15条原始
输入的SHA-256；原始输入一并封存。重新运行报告会在相同覆盖Gate处抛出异常，
这是本轮设计的预期行为。
