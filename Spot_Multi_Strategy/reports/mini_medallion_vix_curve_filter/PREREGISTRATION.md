# VIX期限结构过滤 TQQQ/WTMF + BTC：预注册

本轮不再更换风险资产，而是在当前最接近 Gate 的可交易组合
`TQQQ_WTMF_SWITCH + BTC_TSMOM30_DD` 上检验一个独立、公开且无拟合阈值的
风险状态假说：近端隐含波动高于三个月隐含波动时，SPX 波动期限结构倒挂，
表示即时压力高于中期预期；组合下一交易日转为现金。

Cboe 官方资料定义 VIX 为约 30 天、VIX3M 为约 93 天的 SPX 期权隐含波动。
本实验在提交本预注册前仅核实官方文件地址、字段和日期覆盖，不读取收益统计
或尝试任何阈值。

## 冻结规则

- 评价期固定为 2016-09-12 至 2026-09-10；底层组合直接使用已经冻结并
  计入成本的 TQQQ/WTMF + BTC 1x 日收益，不重新选择资产或参数。
- 当日收盘后计算 `stress = VIX close > VIX3M close`；组合目标仓位为
  `1 - stress`，严格 shift 一个共同交易日后生效，避免未来数据。
- 非压力状态持有底层组合，压力状态持有现金。仓位每次变化收取单边 5bp。
- 只测试固定 1x、2x、3x；2x/3x 的增量敞口按年化 4% 融资，仅在仓位
  实际开启时计费。
- 另对过滤后的 1x 日收益应用一次已冻结风险覆盖（63 日波动、25%目标、
  3 倍上限、8%/20%回撤阈值、0.3最低标量、0.05不交易带）。
- 同时报告未过滤底层组合为对照，共五个场景，不增加或删除场景。
- 初始资本 10,000 美元。

## Gate 与统计检验

所有候选场景统一要求：Sharpe >= 1.5、CAGR >= 40%、最大回撤 >= -20%、
完整盈利年比例 >= 80%、最差滚动三年 Sharpe >= 1.0。对五个场景采用
21 日循环区块 bootstrap 4,999 次、固定种子 514229，并统一进行
Benjamini-Hochberg 校正，要求 FDR <= 5%。

## 停止规则

不根据结果修改 `VIX > VIX3M`、执行滞后、成本、杠杆、风险覆盖或 Gate。
若失败，保留结果并停止对该信号做阈值、均线、连续天数或比例调参；若通过，
仍必须报告逐年、最差滚动三年和最大回撤区间，并进入冻结前瞻验证，不能把同一
历史样本当成部署证明。
