# Mini-Medallion 市场中性多空研究报告

## 背景

用户明确要求放开"现货只做多、不加杠杆"的限制，测试真正的市场中性
统计套利（这是90年代后CTA趋势跟随策略普遍失效后，量化基金真正
转向的方向）。这份报告是一次完全独立的新研究分支：新建
`market_neutral.py`模块，**不修改、不复用**既有的`futures_strategy.py`/
`hybrid_strategy.py`（用户自己在开发的代码）、`risk_overlay.py`/
`ensemble.py`（长仓专用管线）或`paper_state/`（正在运行的模拟盘
状态），一切都是全新代码、全新的模拟运行，不影响任何已有结果。

## 设计

1. **做空腔**：现货本身不能卖空，做空通过Binance永续合约实现，
   所以除了fee/slippage还要计入资金费率成本/收益——多头在资金费率
   为正时付费，空头在资金费率为正时收费。用`futures_data.py`已经
   在抓的真实历史资金费率，因果对齐（`merge_asof(direction="backward")`）
   后按8小时结算/2根4小时K线平摊（简化处理，不是精确结算时点建模，
   已在代码注释里记录）。
2. **完全市场中性、无净杠杆**：每个时间点把各资产的alpha分数减去
   当时所有可用资产的横截面均值（多空双方名义金额由构造本身保证
   接近相等，逐bar验证行和恒等于0），再按总绝对值(gross)缩放到不
   超过1.0倍本金——只缩小不放大，信号弱的时候敞口天然更小。
3. **换手不交易带**：和`risk_overlay.py`对长仓的处理一样，目标
   权重变化幅度不够就不调仓。**这不是可选项，是本次研究实测发现
   的硬性要求**（见下文"过程中发现并修复的问题"）。
4. **Walk-Forward Gate**：criteria和长仓版本的`walk_forward.py`
   完全一样（折IC中位数为正、至少60%折IC为正、单折/单年PnL集中度、
   成本侵蚀比例、最小样本量），只是把"敞口"和"收益"换成横截面
   去均值/超额版本。

## 过程中发现并修复的两个真实问题

这不是"调整到能通过"，是实测过程中发现的构造缺陷，记录下来是因为
它们本身是有价值的方法论发现：

### 1. 成本侵蚀比例(cost_drag_ratio)这个指标本身在高换手场景下会失真

原始定义是`总成本 / 毛收益绝对值之和`。横截面去均值信号逐bar在0
附近噪声很大，"毛收益绝对值之和"会被这些互相抵消的噪声大幅撑大——
实测里`A23_cross_sectional_relative_strength_24`的信号毛收益（有
符号）总和只有+3.19，但绝对值之和高达83.47，导致哪怕总成本
（10.52）已经是有符号毛收益的3.3倍，"成本/绝对值毛收益"这个比例
却只显示12.6%，看起来完全没问题。**已修复**：改成
`总成本 / 有符号毛收益总和`（毛收益不为正直接判定为inf/未通过），
这样才是真正意义上的"成本吃掉了多少可提取的edge"。

这个问题在长仓的`walk_forward.py`里用的是同一个指标定义，但没有
触发，因为长仓alpha的敞口更持续（不会像去均值信号那样逐bar在0
附近震荡），噪声抵消的幅度小得多——**这是一个记录在案但这次没有
修复的长仓侧潜在弱点**，因为修改`walk_forward.py`会影响V1-V1.3
已经发布的历史数字，按"不回头篡改历史报告"的原则保留不动，只在
这里如实说明。

### 2. 没有换手不交易带时，成本会吃掉全部信号

最初的实现没有不交易带，`A23_cross_sectional_relative_strength_24`
在这种设置下：有符号毛收益+3.19，总成本消耗到让净收益变成-8.85。
加了默认5%不交易带后依然是负的（净-7.33），后续做了0.05到0.4的
完整扫描（`stop_loss`式的敏感性检查，不是为了挑一个好看的值），
即使不交易带宽到0.4（几乎不怎么调仓），成本依然是有符号edge的
1.6倍以上。这证明问题不是"没调好不交易带"，是这类alpha在4小时、
4资产的横截面结构下，edge本身相对交易成本就是太薄了。

## 结果：31个alpha家族横截面测试，0个通过

完整数据见`cross_sectional_gate_results.csv`。按折IC中位数排序前5：

| Alpha | 折IC中位数 | 折IC为正比例 | 成本侵蚀比例 | 总PnL |
|---|---|---|---|---|
| A02_ema_distance_20 | 0.0241 | 83.3% | 237% | -3.77 |
| A02_ema_distance_50 | 0.0221 | 83.3% | 217% | -2.89 |
| A01_ts_momentum_12 | 0.0203 | 66.7% | 472% | -9.35 |
| A01_ts_momentum_120 | 0.0200 | **100%** | 452% | -3.26 |
| A16_momentum_ensemble | 0.0191 | 83.3% | 229% | -3.31 |

**没有一个alpha的成本侵蚀比例低于200%**——即使是IC一致性最好的
A01_ts_momentum_120（6折全部方向正确），扣费后的成本也是有符号
edge的4.5倍。31个alpha里大多数败因是同一个模式：折IC本身还算
过得去，但"单折/单年PnL占比"和"成本侵蚀比例"两项同时不达标，
说明这不是个别alpha的问题，是"4小时K线+横截面多资产+持续调仓"这
个结构性组合的edge密度，相对于哪怕是保守的0.10%手续费+0.05%滑点，
都还差一个数量级。

## 诊断性完整回测（不代表通过验收，仅用于量化"差多少"）

用排名最高的A02_ema_distance_50单独跑一次完整的市场中性组合回测
（5000 USDT起始资金，5%不交易带，真实资金费率）：

| 指标 | 结果 |
|---|---|
| 总收益 | **-95.4%** |
| CAGR | -36.8% |
| Sharpe | -1.75 |
| 最大回撤 | **-96.9%** |
| 总手续费 | **26,794 USDT**（起始资金的5.36倍） |
| 年化换手 | 267倍 |
| 完整数据 | `diagnostic_A02_ema_distance_50_equity.csv` |

这组数字把"edge太薄扛不住成本"具象化：6.7年里，仅仅是维持这个
横截面组合的调仓，产生的手续费总额就超过起始资金的5倍，把本来
就单薄的方向性edge完全吞没，还倒贴了大量本金。

## 结论

| 检查项 | 结果 |
|---|---|
| 是否搭建了真正的做空/市场中性架构 | **是**：新的`market_neutral.py`，资金费率感知、无净杠杆、逐资产独立换手控制，完全独立于既有代码 |
| 架构本身是否正确 | **是**：8个单元测试覆盖去均值归零、gross封顶只缩不放、不交易带因果性、资金费率方向、无未来数据泄漏 |
| 31个alpha家族横截面测试通过数 | **0个** |
| 是否发现了真实的方法论问题 | **是**：cost_drag_ratio指标在高换手场景下会失真（已在新模块修复，长仓旧模块保留不动并如实说明）；不交易带对这类策略是硬性要求 |
| 市场中性是否比趋势跟随/长仓alpha库更有希望 | **目前证据上：否**——同一批alpha家族横截面去均值后的表现，比长仓版本更差，不是更好 |
| 核心结论 | **仍不具备模拟盘资格**；这一轮的诚实结果是"放开做空也没有找到edge"，不是"因为限制放开了所以变好了" |

**诚实的解读**：用户提到"90年代之后趋势跟随就不行了，真正的量化
应该做市场中性"，这个判断在方法论上是对的（也是Renaissance等基金
真实走过的路），本次研究认真搭建了对应的架构并跑了完整的实证——
但在**这份数据集**（4个加密货币现货/永续、2020-2026、4小时K线）
上，把现有的35个alpha家族改造成横截面市场中性形式后，edge没有
变得更强，反而因为需要持续调仓维持市场中性，被交易成本吃得更彻底。
这不代表"市场中性思路错了"，更可能代表：（a）4小时K线的换手成本
对这类策略来说太贵，需要更低频的再平衡或更低的实际交易成本；
（b）4个高度相关的加密货币资产横截面广度不够，真正的统计套利
通常需要几十到几百个标的才能把噪声分散掉；（c）OHLCV衍生的35个
alpha家族本身对"谁比谁强"这类相对排序判断力有限。这些都是后续
如果要继续深挖市场中性方向时该关注的具体问题，而不是"多测几个
不交易带的值"这种参数调整能解决的。
