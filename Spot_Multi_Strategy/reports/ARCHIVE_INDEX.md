# 精简与研究审计索引

本目录保留 Mini-Medallion 研究的预注册、数据修订说明和结论文档；可重复生成的行情输入、逐日权益、交易明细、参数网格、CSV、JSON 与 XLSX 不再保存在公开分支的最新版本中。

## 精简原则

- `d9861c9` 继续作为历史保护基准；本次精简不再改动当前 `main` 已保留的核心模块、成熟配置、既有正式报告和模拟盘框架。
- 正式实验在读取结果前必须先预注册；失败结果不得删年份、调参后冒充独立样本外，也不得用杠杆掩盖低 Sharpe。
- 截至本次精简，共审计 103 个同时具备 `PREREGISTRATION.md` 与 `RESULT.md` 的正式实验，没有任何一个通过全部 Gate。
- 失败实验的 Markdown 证据继续保留；其专用策略脚本、测试和大体积数值输出从最新版本移除。
- 被移除文件仍可由 Git 历史恢复；本地完整研究快照另保存在 `local/pre-slim-20261102`，该分支不推送到公开仓库。

## 当前保留范围

1. 成熟基线：`README.md`、核心回测/指标/稳健性/模拟盘模块、三份成熟配置及其既有报告。
2. 通用研究基础设施：组合回测、风险叠加、walk-forward、严格验证、Alpha 生命周期、市场成本、微观结构、HMM、BOCPD 与缠论结构量化模块。
3. 可维护候选：期货趋势、现货/期货混合和多资产轮动的源码、配置、测试及研究说明。
4. 研究审计：各实验的预注册与结果 Markdown，包括失败、拒绝和数据门禁未通过的记录。

## 明确排除

- 一次性失败策略及其同名测试。
- 可重建的行情缓存、逐笔/逐日结果与参数扫描输出。
- 动态模拟盘状态、锁文件、账户资料和任何凭证。
- 尚未完成且测试不通过的 RPHYX 执行包装代码。

候选代码仍只用于研究或小仓位模拟；没有策略因本次精简而被认定为通过实盘 Gate。
