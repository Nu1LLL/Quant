# AQR Style Premia Class N 实盘路径审计预注册

## 目的与证据边界

本轮不发明新的回测信号，而是审计一条 `$10,000` 可实际申购、同时覆盖股票、利率、
商品和外汇，并在价值、动量、carry、防御四类风格中做多做空的基金净值路径：AQR
Style Premia Alternative Fund Class N（`QSPNX`）。固定只使用 Class N，因为其公开
文件列示最低初始投资额 `$2,500`；不以最低投资额数百万美元的机构份额替代。

在写本预注册前，为确认产品仍存续、策略范围和最低投资额，已经看到公开文件中的十年
年化收益摘要。因此本轮明确固定 `independent_oos=False`，只能称“完整逐日路径和杠杆
可行性审计”，不能称首次读取独立 OOS，也不能通过完整严格 Gate。预注册后才允许下载
逐日净值、计算回撤、年度折、滚动三年和 Monte Carlo；无论结果如何均保留。

## 固定数据与覆盖 Gate

- Yahoo 公开 chart 接口，固定请求 `QSPNX` 从 2013-10-30 至 2026-09-15 的日调整
  收盘价；调整价用于纳入基金分配。
- 首日必须不晚于 2013-11-30，末日不早于 2026-08-31，跨度至少 12.5 年，工作日
  覆盖率至少 94%，最大相邻净值缺口不超过 10 个日历日；无重复、缺失、非有限或
  非正价格。任何一项失败，就在绩效前封存，不换份额、不换产品、不移动起点。
- 本轮只审计基金公布净值路径，不尝试从基金持仓逆向重建内部交易；NAV 已包含基金
  内部管理费、交易、空头成本及衍生品盈亏，不另行重复扣除这些费用。

## 固定账户与杠杆情景

- 初始资本固定 `$10,000`；报告 1x、2x、3x、4x、5x 五个数学压力情景。
- 每个情景仅在第一日建立、末日清仓，按总名义本金各扣 10bp；期间不以每日净值变动
  虚构换手成本。
- 超过 1x 的外部资金固定按年化 4%/252 扣融资成本。基金份额未必可按这些倍数获得
  保证金，因此 2x–5x 仅是压力测试，不宣称可直接成交。
- 日收益等于 `leverage * QSPNX_adjusted_NAV_return - external_cost - financing`。
  任一日净收益 <= -100% 即账户归零且不得复活。

- 严格 Gate：CAGR >= 40%、Sharpe > 1.5、最大回撤 >= -20%、PF > 1.3、样本至少
  12.5 年、成本纳入、账户未归零、独立 OOS；由于证据边界已固定为非独立，本轮完整
  Gate 必然不能通过，其他指标仍须原样报告。

  折内回撤 >= -20%；最差滚动三年 Sharpe >= 1.0。
