# AQR Style Premia Class N 实盘路径审计结果

## 结论

**完整 Gate 失败，不进入模拟或实盘。** `QSPNX` 从 2013-10-30 至
2026-09-14 共 3,236 个净值日，工作日覆盖率 96.34%。1x 路径为 8.16% CAGR、
0.916 Sharpe、-41.79% 最大回撤和 1.139 Profit Factor；CAGR、Sharpe、回撤、
Profit Factor、walk-forward 和最差滚动三年均不达标。由于产品核验阶段已看到公开
收益摘要，本轮还按预注册永久标记为非独立 OOS。

这是一条真实的全球多策略、多市场、多空基金净值路径，但不是 40% 年化、Sharpe 1.5
以上、回撤小于 20% 的证据。初始 `$10,000` 的 1x 期末权益为 `$27,452.35`。

2.06%；Sharpe 中位数 0.755、5%分位 0.245；最大回撤 5%分位 -39.26%；PF 5%分位
1.042；四项目标联合通过概率为 **0%**。

封存 `QSPNX` 买入持有及固定外部杠杆假说，不增加择时、不删除 2018–2020、不因为
2022 后表现好而缩短样本。它证明“把多个风格和市场放在一起”本身仍不足以达到目标，
下一轮只能转向新的、预注册前未揭晓绩效的数据或不同经济机制。
