# SVRPO/VXTH 波动率杠铃 + 增长袖套：预注册

本轮是由已观察历史诊断提出、因此必须降级看待的结构组合假说：SVRPO 的定义
风险短波动价差在2018/2022慢熊提供收益但在2020突发跳跃中深度回撤；VXTH
持有动态 VIX 看涨期权，在突发波动中具有相反凸性。固定把二者各半组成波动率
杠铃，再与现有增长袖套等资本配置。

本假说虽然有明确经济互补，但是在看过两个组件同一历史窗口后提出，不是独立
样本外发现。无论结果多好，都只能进入冻结前瞻验证，不能作为十年独立证据。

## 固定数据与权重

- 只复用已经封存的 Cboe SVRPO、VXTH 官方指数收益，以及已封存的
  `TQQQ_WTMF_SWITCH + BTC_TSMOM30_DD` 1x净收益。
- 评价期固定2016-09-12至2026-09-10，取共同美国交易日。
- 波动率杠铃固定50% SVRPO、50% VXTH；完整组合固定50%增长袖套、
  25% SVRPO、25% VXTH。
- 每21个交易日恢复目标权重，中间自然漂移；每单位换手单边5bp。严格不比较
  其他权重、风险平价或择时。

## 固定场景

- 波动率杠铃1x及其冻结风险覆盖。
- 完整组合固定1x、2x、3x；超过1x的增量敞口按年化4%融资。
- 完整组合1x另应用一次冻结风险覆盖（63日波动、25%目标、3倍上限、
  8%/20%回撤阈值、0.3最低标量、0.05不交易带）。共六个场景。
- 初始资本10,000美元；官方指数作为未另扣内部复制滑点的乐观上限。

## Gate 与统计检验

六场景统一要求 Sharpe >= 1.5、CAGR >= 40%、最大回撤 >= -20%、完整
盈利年比例 >= 80%、最差滚动三年 Sharpe >= 1.0。采用21日循环区块
bootstrap 4,999次、固定种子3524578，统一BH校正，FDR <= 5%。

## 停止与实施边界

不根据结果调整三组件权重、再平衡、成本、杠杆或风险覆盖。失败即封存；历史
通过也必须明确标为同样本事后组合，并核实SPX/VIX期权整数合约、保证金、
滑点及10,000美元复制可行性后，进入至少一段未见过的冻结前瞻观察。
