# QQQ长期状态切换增长/波动率杠铃：预注册

本轮检验一个固定状态配置：QQQ长期趋势强时持有已封存的增长袖套
`TQQQ_WTMF_SWITCH + BTC_TSMOM30_DD`，长期趋势弱时持有已封存的
50/50 SVRPO/VXTH 波动率杠铃。经济假说是风险资产趋势期保留增长，慢熊
和急跌期分别由SVRPO溢价与VXTH凸性共同防守。

该假说是在观察同一历史样本中增长袖套与杠铃的年度结果后提出，属于事后研究；
即使历史通过也不能声称十年独立样本外验证，只能进入冻结前瞻观察。

## 冻结规则

- 评价期固定2016-09-12至2026-09-10。
- 状态直接使用已封存TQQQ/WTMF实验的因果仓位：仅月末比较QQQ收盘与过去
  200交易日均线，目标已shift一交易日；`TQQQ=1`定义为风险强状态。
- 风险强状态持增长袖套100%；风险弱状态持波动率杠铃100%。不混合、不设置
  缓冲阈值、不改频率。
- 增长与杠铃收益均已包含各自内部换手成本；两袖套状态切换另按每单位单边5bp
  计费，完整切换换手为2。
- 固定测试1x、2x、3x，超过1x的增量敞口按年化4%融资；另对1x应用一次
  冻结风险覆盖（63日波动、25%目标、3倍上限、8%/20%回撤阈值、0.3
  最低标量、0.05不交易带）。共四个场景，初始资本10,000美元。

## Gate 与统计检验

四场景统一要求 Sharpe >= 1.5、CAGR >= 40%、最大回撤 >= -20%、完整
盈利年比例 >= 80%、最差滚动三年 Sharpe >= 1.0。采用21日循环区块
bootstrap 4,999次、固定种子5702887，统一BH校正，FDR <= 5%。

## 停止与实施边界

不根据结果改变200日、月末频率、两状态资产、杠铃权重、成本、杠杆或风险
覆盖。失败即封存，不追加周频/日频或阈值搜索；历史通过也必须标注事后组合
偏差，并在未见数据上前瞻验证，同时核实SPX/VIX期权整数合约与10,000美元
账户的复制可行性。
