# Snapshot 治理投票参与度异常：严格单次实验封存

**结论：拒绝。** 本实验在独立提交的[预注册](../../research/preregistrations/2026-11-08_snapshot_governance_turnout_spike.md)之后才读取投票参与度和币价，并按照固定代码完成一次正式运行。没有修改代币、年份、门槛、持仓期、成本或杠杆，也没有因 AAVE 或 COMP 的局部贡献而重选资产。全部原始规格、可复现源摘要及机器结果分别见 [PROPOSAL_MANIFEST.json](PROPOSAL_MANIFEST.json)、[SOURCE_AUDIT.json](SOURCE_AUDIT.json)、[RESULT.json](RESULT.json)。

## 固定设计与来源

- 固定 UNI、COMP、SUSHI、1INCH、AAVE 五个 Binance 现货 USDT 币对，各对应预注册 Snapshot 治理空间。2021-01-01 至 2026-01-01 UTC 完整五年，2024–2025 为历史留出期。只在某项提案结束且记录的投票数达到同空间此前六项提案中位数的两倍、且不少于 20 票时，假设延迟 24 小时作出决定，在下一 UTC 日开盘买入，七日后开盘卖出。每币每次最多使用账户权益 20%，无杠杆、无资金费；初始资金 10,000 USDT；每边 10 bp 手续费加 10 bp 不利滑点。
- [Snapshot 官方 Hub API 文档](https://github.com/snapshot-labs/snapshot-docs/blob/master/tools/api/README.md)提供提案和投票字段。本次共保留 1,454 条历史提案记录；其中 264 条未通过预注册的 `scores_updated ≤ end+24h` 可用时间屏选。读取两遍的历史子集摘要一致。官方 Binance Vision 现货日线的 369 个月档案逐包检查 `.CHECKSUM`、完整 UTC 日期网格与 OHLC；ZIP 未保存在仓库。本地仅保存约 0.5 MB 的归一化提案及源摘要，不保存投票人身份或提案正文。
- Snapshot 当前 API 中的最终投票数不是当年 `end+24h` 的原始存档。即使 `scores_updated` 没有超过假定决策时点，仍无法证明所有历史计数在当时可见，也无法恢复后来删除的提案。因此证据等级固定为 `preregistered_retrospective_historical_holdout`，`independent_oos=false`；无论数值如何，完整 Gate 都不能通过。

## 稳定性与限制

- 年度净收益：2021 **0.00%**（无交易），2022 **−2.25%**，2023 **+7.39%**，2024 **−2.87%**，2025 **+6.03%**。年度 walk-forward 的逐年盈利要求失败。
- 按前 90 日 BTC 收益划分的样本状态：熊市 314 天净 **−5.48%**，牛市 686 天净 **−1.28%**，横盘 826 天净 **+15.86%**；不同状态均盈利的要求失败。AAVE 与 COMP 盈利，SUSHI、UNI 和 1INCH 净亏，未据此改变固定池。
- 5,000 条 30 日移动区块重采样中，CAGR 的第 5/50/95 百分位约为 **−2.77% / +1.50% / +7.11%**；联合四项数值 Gate 的概率为零。回测使用日线高低价构造对持仓不利的路径估计，但没有逐笔盘口或订单回执；这不能证明实盘成交和滑点。回溯投票数的时间可见性仍是根本证据缺口。

此次假说已按预注册停止，不在同一段历史上调参或仅保留赢家；不进入模拟盘或实盘。用户原有成熟策略及其他既有封存报告未改动。
