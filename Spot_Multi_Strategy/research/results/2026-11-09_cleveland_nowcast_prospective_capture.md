# Cleveland CPI nowcast prospective capture begins

The new isolated `crypto_blackbox/cleveland_nowcast_prospective.py` records only the **current and previous reference months** from the [Cleveland Fed's official inflation nowcast chart](https://www.clevelandfed.org/indicators-and-data/inflation-nowcasting). Each row is available no earlier than Quant's actual UTC fetch time. The collector accepts the first actual-release chart point only on its release day, and links it to a forecast only if a prior journal row was observed before 08:30 Eastern that day. A late first capture cannot backfill an eligible surprise. It makes no trading decisions or orders. The database is append-only and capped at 16 MiB; the 7.7 MiB source response is not retained.

The source module and three synthetic tests were committed and pushed at `a32b0fb`. Tests covered pre-release forecast, on-release actual with distinct renderer keys, as-of visibility, same-day idempotence, late first capture, duplicate source keys, malformed actual schema and append-only protection. An in-memory live parse returned the two active reference-month identifiers and chart dates without printing values. The runtime copy outside the iCloud worktree matched the repository SHA-256 `a77fe9366a3073d129829acfcf3361fd8b35550550e568680f6e08e24a9aa609`.

The first actual local capture occurred **2026-11-08 16:17:17.913 UTC**: one fresh poll, two forecast rows, zero actuals; database size **32,768 bytes**. A read at one millisecond before that time returns no rows, while a read at the capture time returns exactly two forecasts. The dedicated `com.nu1lll.minimedallion.cleveland-nowcast` user LaunchAgent passed plist validation, launched once, and exited with code **0**; it checks hourly but downloads only once per Eastern business day after 11:00. The initial Sunday capture was explicitly forced to start an honest prospective clock. The WhaleWatcher collector and mature strategy were not edited.

This is **source accumulation, not Alpha**. Five years of genuinely observed data cannot exist before the fifth anniversary of the first capture, and continuity, signal performance, costs, fills and the full Gate remain unproven. The earlier `cleveland_cpi_surprise_btc_spot_2026_11_08` retrospective experiment remains sealed after its parser failure; this journal does not rerun or relabel that result.
