## Independent-source screening

- A new cross-asset Hawkes/network paper cannot be counted as an economically independent source merely because it changes the model: it still tests cross-coin return transmission already preregistered in `2026-11-07_ten_coin_delayed_leadlag.md`. [The new paper](https://papers.ssrn.com/sol3/Delivery.cfm/7597918.pdf?abstractid=7597918&mirid=1) is a possible methodological comparison, not a fresh Alpha family on the same historical returns.
- [The Bitcoin price-clustering study](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3001719) reports round-number clustering but no significant return pattern after round numbers. It does not justify an unfrozen round-price trading screen.
- [Coin Metrics documents](https://docs.coinmetrics.io/network-data/network-data-overview/exchange/point-in-time-flows) point-in-time exchange deposit flows, a more causally sound source than current-address backfills. A price-blind query of the unauthenticated community `catalog-v2/asset-metrics` returned **no entitled BTC `FlowInExPitNtv` entry**, whereas `catalog-all-v2` returned one. Its *catalogue bounds*, which are not proof of non-null daily observations, start in 2009 for BTC and 2015 for ETH; hourly bounds start only in 2025. This is an access finding, not a licensed download or a backtest. Its exchange-deposit mechanism overlaps the prior exchange-inventory hypothesis in part and would need a separately justified independent transfer rule. Retrospective point-in-time address attribution published recently is not five years of prospective publication evidence.
- [DefiLlama's unlock definition](https://docs.llama.fi/analysts/data-definitions) describes a distinct supply-event mechanism, but its [Pro API listing](https://api-docs.defillama.com/) requires an API plan for the unlock feed. Historical first-published calendars, five-year continuous events and venue-executable costs have not been established. No token-unlock candidate is registered from an unverified current schedule.

**Decision:** leave the existing 12-symbol forward collector running through its frozen activation, then audit its first sealed hour. Continue searching for a genuinely distinct five-year source; do not rebadge prior lead-lag, average-trade-size, or exchange-supply mechanisms as new experiments. Neither the WhaleWatcher historical CPI comparison nor any backfilled market series is independent five-year executable OOS.
