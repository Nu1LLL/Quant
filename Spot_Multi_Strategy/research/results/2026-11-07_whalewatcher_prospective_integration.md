# WhaleWatcher prospective provenance bridge (no strategy result)

**Date:** 2026-11-07. **Status:** operational shadow-data capture, not an Alpha, OOS pass or trading authorization.

The existing fail-closed readers in `research/crypto_blackbox/whalewatcher_event_shadow.py` and `whalewatcher_shadow_adapter.py` consume only local WhaleWatcher snapshots. The new `whalewatcher_prospective_journal.py` records **changes** to their redacted event/claim metadata in append-only SQLite. It retains hashed IDs and URLs, source/category, asserted side, publication/first-seen/Quant-read times and source snapshot hash. It copies no article prose, raw URLs, post-event returns, AI advice, account information or orders. Historical reads (`read_asof`) cannot see a change before Quant captured it; a future-dated source publication also waits until that later timestamp. Repeated snapshots or changes confined to article prose add no rows. Removed/corrected items remain auditable as time-stamped changes. The SQLite file has a **64 MiB hard cap**.

On this Mac, the isolated local deployment is under `~/Library/Application Support/MiniMedallion/`; `com.nu1lll.minimedallion.whalewatcher-shadow` runs the collector hourly through a user LaunchAgent. The runtime's three Python modules were copied byte-for-byte from the repository source because a LaunchAgent importing code directly from the iCloud worktree blocked during Python startup. After switching to the local copy, the first scheduled run exited with code **0**. The initial journal was **77,824 bytes**. A prior whole-snapshot prototype was migrated into the delta schema and compacted; its original capture timestamps were preserved.

At the first actual read the current WhaleWatcher snapshots supplied **164** event metadata rows (all Bloomberg), **0** independently verified BTC directional claims and **0** ETH claims. Source publication dates ranged from **2026-10-30 to 2026-11-07**; WhaleWatcher first-seen dates ranged from **2026-11-03 to 2026-11-07**. This is only days of prospective evidence, far short of five years. It is not suitable for a historical trading Gate, and no return, correlation, Sharpe, PnL or order was generated from it. The journal is an input to future, separately preregistered hypothesis tests only after a complete point-in-time sample exists.
